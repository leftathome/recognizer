If DaemonSet pods stay Pending, the most common causes are:

  1. NFD isn't installed or its worker rules don't produce the labels
     this chart's nodeSelectors expect. Verify with:
       kubectl get nodes -l {{ if .Values.opticalRipper.enabled }}{{ .Values.opticalRipper.nodeSelector | keys | first }}{{ else }}{{ .Values.documentScanner.nodeSelector | keys | first }}{{ end }}
     If empty, NFD is not configured for this hardware -- see the chart README "Cluster prerequisites".

  2. smarter-device-manager isn't running on the target node. Pod admission
     fails with "Insufficient smarter-devices/...". Check the smarter-devices
     resource availability on the target node:
       kubectl describe node <node> | grep smarter-devices

  3. The PVC isn't bound. Check:
       kubectl -n {{ .Release.Namespace }} get pvc {{ include "recognizer.fullname" . }}-data
